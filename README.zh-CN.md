# WAV Compare

[English](README.md) · [比较规则](docs/comparison.md) · [版本发布](docs/releasing.md)

跨平台 WAV 音频比较工作台与命令行工具，覆盖 **8 kHz 起的音频**、多声道和长音频目录批处理。

![使用合成音频的工作台](docs/images/workbench.png)

## 安装与启动

安装 [uv](https://docs.astral.sh/uv/getting-started/installation/) 后执行：

```sh
uv tool install --python 3.14 git+https://github.com/sunging/wav_compare.git
wav-compare
```

支持 Python 3.11 及以上，开发环境固定为 3.14。找不到命令时执行 `uv tool update-shell` 并重新打开终端。无需 PyPI 即可安装。

首个正式版本 `0.1.0` 通过发布 PR 准备，合并之前 main 的包版本为未发布的 `0.0.0`。正式发布后才可在 Git URL 后添加 `@v0.1.0` 安装固定版本。

## 使用

- 打开或拖入两个文件/目录后自动比较；路径或分析参数停止变化 400 毫秒后计算，连续修改只计算最新输入。目录按相对路径递归配对，明确显示缺失、冲突和错误；每完成一个文件就立即加入结果表，并自动打开首个可分析结果（或上次选中的路径），无需等待整批结束。结果表列出状态（按颜色区分）、最大差异、时延、RMSE 和 SNR，数值列按数值排序。可将单个文件拖到 A 或 B 输入框只替换该侧；拖到窗口其他位置时，两个路径分别填入 A/B，一个路径填入空缺的一侧。
- 顶部紧凑文件区与菜单栏保留常用入口。“文件与结果”和“参数与指标”可通过栏标题箭头、顶部开关或“视图”菜单独立收起，释放图表空间；展开恢复原宽度。“视图 → 重置布局”恢复默认布局，不重置分析参数。
- 默认将 **B 重采样至 A 的采样率**，再估计固定时延。A 为 8 kHz 时目标就是 8 kHz。严格模式关闭两项处理。参数分为“对齐”“比较”“显示”三组，当前模式下不起作用的选项会自动置灰（如严格模式下的对齐与时延）；声道配对无效或与“混为单声道”冲突时输入框标红并提示原因。
- “分析结果”以分组表格显示概要（含对齐置信度或未对齐原因）、声道指标和未比较部分，右键可复制所选或全部内容；参数区与结果区之间的分隔条可拖动。
- 支持逐声道比较、输入 `1:1,2:2` 自定义声道配对，或显式混为单声道。
- 查看波形、差值、分段统计、频谱和声谱图；支持选区分析、联动缩放、最大差异和前后差异定位。差异定位使用独立的红色标记，从上一次定位处继续查找，不受播放光标影响；停止且未循环时播放位置同步移到该差异处，可直接试听。播放时间轴上的橙色热度条显示整段差异分布。FFT／帧移变化仅自动更新频谱；在波形页调整时，进入频谱页才计算。在频谱与声谱图之间切换、切换试听音源不会重复计算。拖动选区不自动重算，通过图表下方“选区”菜单或“分析”菜单执行选区比较、全段比较或更新频谱。
- 选区编辑区支持**秒、时:分:秒、采样**三种格式，以及**起点／终点、起点／长度、长度／终点、中心／长度**四种选择类型。标签紧贴输入框，窄窗时格式与类型自动移至上一行。格式和类型会被记住，切换不会改变实际选区，也不会重算或重启试听；时分秒支持超过 24 小时的时长。
- 位置使用当前分析结果的采样率，从图表起点的第 0 个采样边界计数，终点不包含在选区内，长度等于终点减起点。输入和拖动均吸附到采样边界，至少保留一个采样。回车或失焦确认数值，步进按钮每次调整一个采样；无效输入恢复上次有效值。移动锚点保持长度并限制位置，修改长度保持锚点并限制长度。中心可用半采样位置；长度奇偶变化时，实际中心可能校正半个采样并回显。对子选区再次分析会按采样数累加原点偏移。
- 每个图都有独立的“显示指示器”开关，默认开启并记住设置。悬停查看数值，单击固定／解除固定，读数可选中复制；各图固定位置互不影响，播放不会覆盖读数。分段图显示原始分段统计，频谱显示 PSD（dB/Hz），声谱图显示对应分析帧的实际幅度（dB），不受颜色范围截断。采样点和分段序号从 0 开始。
- 在波形图内按住拖动可平移，拖动坐标轴只平移对应方向；拖动选区边界可调整选区。平移限制在音频时长和当前声道的全局幅度范围内，并保留少量边距；“重置缩放”恢复完整视图。
- 频谱图、声谱图的频率限制在 0 到奈奎斯特频率；频谱功率范围按分析结果保留边距，声谱图时间限制在已分析选区内。“重置缩放”也会恢复这两类图表。
- 试听 A、B、差值，支持选区循环、暂停和跳转；播放音量不改变分析。原始输入试听使用原文件的秒数，处理后试听使用对齐后的时间轴。
- 底部播放时间轴单击定位，拖动建立选区（支持反向拖动），拖动两端调整范围，右键可“选择全部”；选区与波形和起止时间同步。定位保持播放／暂停／停止状态，停止保留位置。不循环时播放到音频末尾，循环时只播放选区；从选区中间定位后，下一轮恢复完整选区。左右键定位 ±0.1 秒，Home／End 定位到有效播放范围两端；播放到末尾后再次播放从起点开始。更换音源会停止播放，原始试听范围截断到原文件末尾。
- 单文件导出反映当前选区分析；目录导出包含整批结果。JSON/CSV 保留实际参数和异常状态。
- “设置 → 偏好设置”提供中英切换、系统/浅色/深色主题、自动比较、启动时自动比较与恢复上次路径；后三项默认开启。沿用本机 QSettings 保存分析参数、侧栏状态、窗口布局、频谱参数、音量与试听偏好；不保存结果、播放进度或临时选区。关闭路径恢复会清除保存的历史路径，启动时显式传入的路径仍优先使用。
- 可随时手动重新比较；Esc 同时取消等待中的自动比较与后台任务，取消后不会自行重试，直到再次修改输入或手动比较。关闭自动比较不打断已运行任务。导出位于“文件”菜单，清理缓存位于“分析”菜单。快捷键：Ctrl+Enter 比较，Esc 取消，Ctrl+0 重置缩放，Space 播放／暂停／继续（停止时开始播放），Ctrl+Q 退出。“系统”主题会跟随系统深浅色的实时变化。

```sh
wav-compare compare a.wav b.wav --json report.json --csv report.csv
wav-compare compare before/ after/ --strict --threshold 0.0001
wav-compare compare a.wav b.wav --offset 160 --region 2 8
```

正时延代表 B 比 A 晚，单位为 A 采样率下的采样点。阈值随数值模式变化：浮点模式使用归一化幅度，PCM 模式使用整数码值。退出码 0 表示满足条件且阈值内，1 表示差异或缺失，2 表示错误或无法比较，130 表示取消。

## 长音频与限制

分块读取、流式重采样、后台分析和多级波形包络避免全量音频常驻内存。视口缓存预算为 256 MiB，后台最多两个任务；切换目录结果不会重新分析整个目录。

自动对齐仅补偿固定时延，不修正变速、时钟漂移或内容增删。无法可靠估计时显示“未可靠对齐”。频谱/声谱图按选区生成，长选区声谱图是最多 512 时间列的概览，缩小选区可查看细节。

Windows 已进行真实窗口和音频设备测试；三平台 CI 覆盖自动化测试。Debian/Ubuntu 需安装 `libegl1 libopengl0 libxkbcommon0 libpulse0` 及桌面环境的 Qt/XCB 依赖，试听还需可用音频服务。无输出设备仍可分析和导出。无音频设备的 CI 不代表试听已验证。

性能见 [报告](docs/performance.md)。重采样缓存需要额外磁盘空间，不修改原音频。正常关闭、结果淘汰及“清理缓存”会释放临时数据。
